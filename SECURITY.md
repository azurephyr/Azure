# Security Policy

Azure is early-stage software. Please do not disclose security vulnerabilities in public issues when they could expose credentials, authorization bypasses, or private Discord data.

## Reporting

Until a dedicated security contact is configured, open a private GitHub security advisory when GitHub makes that option available for this repository. If that option is unavailable, contact the maintainer through their GitHub profile before public disclosure.

Never include Discord bot tokens, API keys, personal data, or other secrets in a report.

## Scope

Security reports involving permission bypasses, unsafe command execution, secret exposure, data isolation, or moderation authorization are especially important.
