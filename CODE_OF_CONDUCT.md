# Code of Conduct

## Our commitment

We want Azure AI to be a welcoming, respectful, and constructive open-source project. Contributors and maintainers should be able to collaborate without harassment or discrimination.

## Expected behavior

Participants are expected to:

- Be respectful and constructive.
- Assume good faith while discussing technical disagreements.
- Focus criticism on ideas, code, and behavior rather than people.
- Respect different backgrounds, experience levels, and viewpoints.
- Protect other people's privacy and confidential information.
- Follow the project's security and contribution guidelines.

## Unacceptable behavior

Unacceptable behavior includes harassment, threats, discrimination, deliberate intimidation, publishing private information, sexualized harassment, and sustained personal attacks.

Security vulnerabilities and private information should never be disclosed in public issues or pull requests.

## Enforcement

Project maintainers may remove, edit, or reject contributions and may restrict participation when necessary to keep project spaces safe and constructive.

Serious or repeated violations may result in temporary or permanent removal from project spaces.

## Reporting

For conduct concerns, contact the project maintainer privately through the GitHub profile associated with this repository. Do not include passwords, API keys, bot tokens, or other secrets in a report.

For security vulnerabilities, follow [`SECURITY.md`](SECURITY.md) instead.

## Scope

This Code of Conduct applies to project repositories, issues, pull requests, discussions, and other spaces operated for the Azure AI project.
